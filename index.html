Tentang Saya

Mimpi Besar di Teknik Elektro

Halo! Saya Aleano. Sejak kenal dengan dunia teknologi, saya punya tekad kuat untuk bisa masuk ke Institut Teknologi Bandung (ITB) jurusan Teknik Elektro. Saya percaya bahwa teknik elektro adalah kunci untuk membangun infrastruktur masa depan yang cerdas dan berkelanjutan.

Di samping ketertarikan saya pada hardware dan kelistrikan, saya juga sangat menikmati proses problem solving. Mencari tahu bagaimana suatu sistem bekerja dan memperbaiki celahnya adalah hal yang memuaskan buat saya. Itulah mengapa saya juga belajar web development dasar seperti HTML dan CSS untuk menyeimbangkan logika dan kreativitas.
